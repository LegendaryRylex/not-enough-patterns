### Added
- Filling and Deploying patterns in the Assembly Matrix, which runs those recipes on its own with no Depot, Spout or Deployer built.

### Fixed
- Recipes transferred from another mod's recipe viewer category being encoded as a NEP pattern whenever a NEP machine happened to take the same ingredients.
- Items with more than one Fusion Crafting recipe, such as the Chaotic Staff, encoding as a plain processing pattern the Fusion Crafter refuses. {#2}

### Changed
- Injector Fusion Matrix, the new name of the Fusion Matrix, along with its GUI, block, item and Fusion Crafting Pattern art.
- Assembly Matrix, the new name of the Sequenced Assembly Matrix.
- Miniaturization Matrix, Miniaturization Controller and Miniaturization Pattern art, now teal to set them apart from the Injector Fusion Matrix.
- Incomplete Matrix item art, to better match the complete item.
- Creative Tab icon, now the Import Card so it stays the same across game versions.
