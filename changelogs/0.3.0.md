# Added
- Ars Nouveau machine patterns. An Enchanting Apparatus or Imbuement Chamber with a Pattern Provider against it takes a whole craft at once, with the reagent going into the machine and one ingredient onto each surrounding Arcane Pedestal. The Arcane Core under an apparatus accepts a Provider just as well.
- Arcane Lectern. Presents an ME network to Ars Nouveau the way a Storage Lectern presents its linked chests, so a Scribes Table draws glyph reagents straight out of the network, along with anything else that pulls from a neighbouring inventory.
- Ritual automation. The Ritual Conductor keeps a nearby Ritual Brazier running by itself, drawing its tablet from the ME network, feeding the augments it was configured with, and lighting the ritual once its conditions are met; the Ritual Collector takes what the ritual produces back into the network, both from the Brazier directly and from anything the ritual drops nearby.
- Machine Hub. Presents several separate inventories to a Pattern Provider as one, so a multiblock whose item and fluid hatches are individual blocks takes a whole pattern at once, and returns whatever lands in the linked outputs to the network. Links come from the Hub Linker or the Hub's own scan.
- Processing Pattern Conversion. Craft any NEP pattern back into a plain AE2 Processing Pattern with the same ingredients and result. Avoids future soft-lock issues for highly-customized packs.

# Fixed
- Sequenced Assembly Linker opening a target's own screen instead of linking it, so a chest or barrel could never be set as the input or output by clicking it.

# Changed
- Atomic Reconstruction Patterns now push their ingredients into adjacent inventories like plain processing patterns so the real Atomic Reconstructor can be automated with these patterns.
- Pattern Encoding Terminal now keeps the ingredient slots exactly as they were laid out, both after encoding and when a NEP pattern is put back in to be edited, instead of packing them to the front.
