# Added

- Create Mechanical Crafting support: a Pattern Provider adjacent to a Mechanical Crafter grid runs the recipe as an autocrafting step, for grids up to 9x9.
- Deploying support: a Pattern Provider pointed at a Depot under a Deployer runs `create:deploying` recipes.
- Filling support: a Pattern Provider pointed at a Depot under a Spout runs `create:filling` recipes.
- The Import Card, slotted into a Pattern Provider, will collect its own results from machines that expose their output.
- Sequenced Assembly Controller. Runs a whole `create:sequenced_assembly` belt line as one autocrafting step, automatically feeding every station, injecting the base item, recirculating the part, and returning the result to the network.
- Sequenced Assembly Matrix, runs the entire sequenced assembly recipe internally with no belt line, always yielding the primary result (configurable).
- Matrix Circuitry and Hardened Obsidian Plate as crafting components.
- Jade support showing status, active outputs, missing materials, stress draw, and craft progress.
- Create goggle tooltips for the Matrix.
- JEI integration: pattern transfer from any supported Create recipe type, and the machines listed as recipe catalysts.
- AE2WTLib support so patterns can be encoded from wireless terminals.
- In-game GuideMe guide covering every integration, with a per-page banner when a module is disabled.
- Per-module config in `nep-server.toml`: each integration toggles on its own, a master override switches all Create integrations off at once, and a debug section enables verbose push logging.
