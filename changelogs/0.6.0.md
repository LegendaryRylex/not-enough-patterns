### Added

- Manual crafting support for matrices.
    - Press a recipe's transfer button in JEI with the Matrix open and its ingredients move from your inventory into the machine, with the result left in the output buffer instead of going to the network.
    - Shift-click queues as many crafts as you can pay for.
    - Missing items are highlighted in JEI.
- ExtendedAE pattern viewing. Its view hotkey now opens NEP pattern types.
- Matrix tooltips naming the mod and the recipe types each Matrix runs.
- Pattern Decoder, a gate on encoding NEP patterns. When enabled, a Pattern Encoding Terminal only encodes a mod's NEP patterns when a powered Decoder on its network carries that mod's Encoding Module, and writes a plain Processing Pattern otherwise. Off by default.

### Fixed

- Outputs that carry data component information now automate at every Matrix and at the Sequenced Assembly Controller. A pattern whose result is enchanted, damaged, dyed, filled or otherwise stamped is accepted rather than refused, two variants of the same item queue as separate jobs, and each one goes back to the network in the form its pattern named.
- Import Card now collects a craft's fluid results as well as its items, so a Create Basin recipe that leaves a fluid behind no longer strands it in the basin.

### Changed

- Matrix block textures are now an open frame with a glowing sphere turning inside them. The core drifts while the Matrix is idle, spins up and brightens as a craft runs, flares when the craft lands, and judders in place when the Matrix stalls. Every Matrix family has its own core art, and neighbouring Matrices are offset from one another so a wall of them never turns in lockstep.
- Machine Hub, Miniaturization Controller, and Sequenced Assembly Controller models in place of their plain cubes.
- GuideMe recipe compat is now its own separate mod.
