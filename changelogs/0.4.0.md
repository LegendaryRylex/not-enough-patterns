### Added
- Machine Hub: 
    - Scan configurations: a scan whitelist, scan blacklist, and link blacklist, each as a config list and as a block tag, so packs and mods can declare a custom multiblock the built-in rules would misread. Common player storage and general terrain and building blocks ship blocked, and the link blacklist also binds the Hub Linker.
    - GUI rework: Any linked inventory has filters with allow or deny modes per filter, the machine face the Hub reaches through, and a fill priority. Filters take items and fluids alike. Includes JEI drag support or from player inventory.
    - Wrenching. Sneak and use any wrench on a Hub to pick it up with its links and everything configured for them intact, and place it again to restore every link still in range.
- Direct GuideMe buttons on every machine screen as a question mark in the top right of the GUI.
- AE2 Lightning Tech support for channel and network calculations.
- ME network channel configuration. Every matrix and the Machine Hub can now take up more channels on a network it is connected to, configurable per machine. A matrix takes 15 by default and the Machine Hub 11, and the Hub takes one more for each inventory it is linked to.

### Changed
- Machine comparator output, which now always reads how full a machine's output buffer is. The signal button that cycled between the output buffer, the input buffer and machine status is gone, and its place in the top row is taken by the new guide/help button.
- Machine screen icons now come from a custom font shipped with NEP rather than plain text.
- Matrix buffers now hold up to 64 of any item per slot regardless of its stack size, so a pattern demanding many unstackable items no longer misreports an empty buffer as full and refuses to start

### Fixed
- Machine Hub extraction, which ignored a link's role and let the network pull ingredients back out of a machine it had just filled. Only links that output give anything back now, while what a Hub reports stays unchanged so AE2 blocking mode still sees ingredients waiting in an input machine.
- Enchanting Pattern experience payment being replaced with the first tagged fluid instead of keeping the fluid or bottles already chosen in the grid.
- Auto-requested crafting deliveries, which told the crafting CPU the opposite of what a machine had accepted, duplicating items into network storage when a buffer took them and voiding them when it was full.
