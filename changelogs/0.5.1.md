### Added

- Deployer support for Create's sandpaper polishing recipes. Polishing was filed under its own recipe type, so the **+** in JEI gave back a plain processing pattern that no Depot would take and Polished Rose Quartz could not be automated at all. It now encodes as an Andesite Crafting Pattern with the sheet retained, and runs on a Depot under a Deployer holding sand paper. LegendaryRylex/not-enough-patterns#5

### Fixed

- A cancelled fusion craft left its catalyst and every loaded ingredient sitting in the Crafting Core, which then read as *Ready to craft* and waited for someone to press the button. Nothing could clear it, so the Core stopped crafting on its own from then on. All of it now goes back to the Pattern Provider when a craft is cancelled, and a Core found sitting loaded from an earlier craft, whatever left it that way, is emptied into the Provider and restarted on the next push. LegendaryRylex/not-enough-patterns#6
- A push the Crafting Core turned down left the recipe it had selected set on the Core. The items were taken back but that selection stayed, which is enough to confuse another mod driving the same Core. A refused push now leaves the Core exactly as it found it.
- A Sequenced Assembly pattern ran under whichever recipe came first for its output rather than the one the pattern names. Where a pack adds a second recipe for the same item, such as a Precision Mechanism assembled from an Overcharged Golden Sheet instead of a plain one, the Controller asked for the other recipe's base item and left the one the pattern supplied sitting unused in its buffer. The Controller and the Sequenced Assembly Matrix now remember the recipe each pattern was encoded for.
- Two Fusion Crafting patterns for the same item, encoded from different recipes, could both be queued on the Injector Fusion Matrix. The second overwrote the first's stored recipe and ingredient list, so both crafts ran under one recipe while the other's ingredients sat unused in the buffer. The Matrix now turns the second pattern down until the queued craft finishes, as its sibling machines already did.

### Changed

- Sable Companion is no longer packaged inside the NEP jar. Sable sub-level support now goes through an optional compat layer that only turns on when Sable Companion is present, which Sable already ships with itself, so nothing changes for Sable users. Installs without Sable no longer get an extra library mod added to their mod list.
- Guide pages no longer quote settings as fixed numbers. Channel counts, tank sizes, power draw, shaft speed floor, link range and the Import Card grace period are read from the running config wherever a page mentions them, so a pack that retunes NEP no longer leaves the guide describing something else. One of those numbers was already wrong: the Infused Awakening Matrix page claimed an essence tank holds 64 when the default is 40.
