# Added

- Brazilian Portuguese translation, contributed by PrincessStellar.
- Draconic Evolution Fusion Crafting compat.
    - Direct Pattern support for the Injector.
    - Fusion Matrix, a single block that replaces the whole Crafting Core and Injector setup. Can be upgraded with Cores.
    - QOL: Gear auto-crafting upgrades to the Chaotic tier and carry its energy, modules, and enchantments onto the result, exactly as a hand craft does.
- Log stripping to Create Deployers.
- Apothic Enchanting infusion compat on the Enchanting Table of the Raven.
- Compact Crafting miniaturization compat.
    - Miniaturization Controller manages block-placing within a projector field in-world.
    - Miniaturization Matrix, a single block that runs a whole miniaturization recipe with no projectors and no field.
- Actually Additions Empowering compat.
    - Atomic Empowering Matrix, a single block that runs both Empowering and Atomic Reconstructor recipes.
- Mystical Agriculture compat.
    - Infusion and Awakening recipes can run directly from an attached Pattern Provider on either altar.
    - Infused Awakening Matrix, a single block that runs both Infusion and Awakening recipes with no pedestals and no vessels.
- Ingredients not consumed in a recipe are now highlighted in yellow inside the terminal and listed apart on the pattern tooltip as returning to the network. An ingredient a recipe both consumes and keeps encodes into two slots, so the kept part carries its own highlight.
- Descriptions on every setting in the config screen, translatable alongside the setting names rather than English-only, and each numeric setting now states the range it accepts.
- Import Card support for other addon mods' pattern providers: Advanced AE, ExtendedAE, MEGA Cells
    - Includes support for Applied Create and AE2 Draconic Fusion, though both mods are made redundant with NEP.
- Sable Support for airships.

# Fixed

- Every machine screen closing the instant it opened aboard a Sable ship. Sable keeps a sub-level's blocks parked in a plot far from where the ship is drawn, so the plain distance from the player to the block was thousands of blocks; reach is now measured after both are projected back into the world.
- Sequenced Assembly Linker drawing its boxes and beams at a ship's parked plot rather than on the ship. The whole overlay now rides the sub-level's render pose, so it rotates and moves with the deck under it.
- Sequenced Assembly Linker reporting a link that crossed a ship boundary as merely too far away. Every link is now required to sit on the same sub-level as its controller, and says so when it does not.
- Every matrix and the Sequenced Assembly Controller duplicating their whole contents when a ship was assembled around them. Sable copies a block entity into the sub-level and then removes the original, and the removal was dropping everything the copy already held; each now clears itself on capture.
- Import Card going into other mods' upgrade slots when Shift+Clicking in the GUI.
- Import Card losing the results already in flight when a crafting job was cancelled partway through. Cancelling now leaves the card a grace period to collect what each machine was still working on, tuned by `importCardGrace`.
- Clear Pending Recipes leaving the crafting job stuck on the network.
- Sequenced Assembly Controller ignoring recipes that repeat a step, such as Create's Track with its two identical Deploying steps. A line is now matched station for station against the recipe sequence, so repeated Deploying, Pressing, Sawing and Filling steps each ask for their own machine.
- Sequenced Assembly Controller stranding the parts already traveling down its line when its pending recipes were dropped or its buffers emptied. It now keeps clearing its output Depot for a grace period afterwards, tuned by `reclaimGrace`, and banks what arrives as network stock.

# Changed

- License, now All Rights Reserved rather than MIT. Modpacks may still ship unmodified releases as long as they credit the mod and link an official download page.
- Import Card installation now also accepts Sneak+Use on a Pattern Provider with the card in hand, including when a Memory Card copies one Provider onto another.
- Module config layout, so a module whose only setting is its on/off toggle now sits as a single switch on its mod's page instead of a submenu holding one switch.
- GuideMe modules no longer display if its related mod isn't installed.
